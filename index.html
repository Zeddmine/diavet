Réception Automatique sur Google Sheets (Gratuit)

Vous pouvez recevoir chaque nouvelle inscription instantanément dans une feuille Google Sheets sur votre compte Google ou via Zapier / Make / Formspree.

Étape 1 : Créez votre script Google Sheets en 2 minutes

  1. Ouvrez une feuille Google Sheets vide et nommez-la « DiaVet Algérie — Inscriptions ».
  2. Dans le menu supérieur, cliquez sur Extensions > Apps Script.
  3. Supprimez le code présent et collez le script ci-dessous :
function doPost(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); if (sheet.getLastRow() === 0) { sheet.appendRow(["Date", "Ref VIP", "Type", "Nom", "Wilaya", "Commune", "Contact", "Canal", "Animal / Clinique", "Budget / Honoraires", "Avis / Manques"]); } var data = JSON.parse(e.postData.contents); sheet.appendRow([ data.timestamp || new Date().toLocaleString(), data.id, data.profileType, data.fullName, data.wilaya, data.commune, data.contactValue, data.receiveChannel, data.animalType || data.clinicName, data.monthlyBudget || data.consultationFee, data.missingThings || data.topPain || "" ]); return ContentService.createTextOutput(JSON.stringify({status: "success"})).setMimeType(ContentService.MimeType.JSON); }
